# Personal Portfolio

> A modern, responsive personal portfolio website designed to showcase my skills, projects, services, and experience as a developer.

Welcome to my personal portfolio! This project was built from scratch using **HTML, CSS, and Vanilla JavaScript**, with a focus on clean design, responsive layouts, smooth interactions, and a simple user experience.

The portfolio serves as a central place to explore my development journey, discover the projects I've worked on, and learn more about the services and skills I can offer.

## About The Project

I created this portfolio to build a professional online presence and put my front-end development skills into practice.

Rather than relying on a framework, the project uses **pure HTML, CSS, and JavaScript**, allowing me to strengthen my understanding of the fundamentals behind modern web development.

The website is designed to be:

* Clean and modern
* Fully responsive
* Easy to navigate
* Interactive and engaging
* Accessible across different screen sizes
* Focused on presenting projects and skills clearly

## Features

### Responsive Design

The layout adapts to different screen sizes, providing a consistent experience across desktops, tablets, and mobile devices.

## Design Goals

The main goal of the design was to create something that feels **professional without being complicated**.

I focused on:

**Clarity**
Visitors should immediately understand who I am and what I do.

**Responsiveness**
The website should work comfortably on both large and small screens.

**Interaction**
Animations and hover effects should make the interface feel alive while remaining subtle.

**Simplicity**
The design avoids unnecessary elements so the important information stays easy to find.
